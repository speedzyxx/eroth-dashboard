# Desplegar Eroth Dashboard (GitHub + Render)

Mismo flujo que African Push / Digital Academy.

## 1) Código en GitHub

Ya puedes crear el repo y hacer push (o usar los comandos que dejó el agente).

## 2) Render (Blueprint)

1. Entra a [dashboard.render.com](https://dashboard.render.com)
2. **New +** → **Blueprint**
3. Conecta el repo `eroth-dashboard`
4. Confirma el `render.yaml` → **Apply**
5. Espera 3–8 minutos

URL típica: `https://eroth-dashboard.onrender.com`

Atajo Blueprint (con el repo creado):

https://dashboard.render.com/blueprint/new?repo=https://github.com/speedzyxx/eroth-dashboard

## Nota plan Free

El servicio se duerme ~15 min sin visitas; la primera carga puede tardar 30–60 s.
